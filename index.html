🛠️ Build or Update a Game

This is where we start making a game. It can be any kind of game you can think of, but you need to give Daddy's Game Maker as much detail as possible.

How to make a good game:
1. Pick New Game or Update My Game.
2. Explain the game you imagine with lots of details.
3. Talk-to-text works here, but speak clearly so the game idea comes out right.
4. The more detail you give, the better the game can be.
Pick a game from the GitHub game folders. The builder will prepare an update request for that current game.

🔗 Copy a Game Link

Choose a kid, then choose a game from that kid's GitHub game folder. The workshop can scan the public GitHub games folder and copy the real playable link.

Share a real game:
1. Pick the kid.
2. Pick the game.
3. Tap Copy Selected Game Link.
4. Send that link to a friend.
The game list checks GitHub when you open this share screen and re-checks when you switch kids. Upload each game as an index.html file inside that game's folder.
