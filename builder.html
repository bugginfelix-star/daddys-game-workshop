This is Dad’s secret video game builder for Quinton, Lincoln, Adella, and Gemma. Make a new game, update an old one, save it to a bucket, or create a play-only link to send to friends.

🎮 Step 1: Describe the Idea

Create a new game idea or update one already saved on this device.

How to use this builder:
1. Choose New Game or Update My Game.
2. Fill in the idea and game parts.
3. Tap Generate Starter Game.
4. Save it to a kid bucket or copy a share link for friends.
Pick an older game and the builder will fill in what it knows from the last version.
Ready.

👀 Step 2: Try the Starter Preview

This preview becomes the play-only shared game. It is simple on purpose, but it proves the sharing system works.

🧰 Step 3: Share / Dad Tools

Copy the link to send a play-only game to friends, or copy the Dad prompt to make a bigger custom game later.

The shared link opens through index.html#play=.... Friends can play that one game, but they cannot see family buckets.
